## Purpose of References

These references were used to support the technical information presented in
the Week 3 Enterprise Server Deployment project, including Ubuntu Server
installation, server configuration, SSH, systemd, BIOS and UEFI technologies,
boot processes, virtualization, and comparisons between Windows Server,
Ubuntu Server, and Rocky Linux.

The sources were selected primarily from official documentation and
organization websites to improve the accuracy and reliability of the technical
information presented in this portfolio project.
